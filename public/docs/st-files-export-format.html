Source formula

The "Spaces" row's own formula from the property's Google Sheet ("Siam-ST"), cell A1 — this is what resolved fields 5 and 17.

="PMSST|RMSST|"&"90107"&"|"&text('Parameters-Availability'!$B$7,"ddmmyyyy")
&"|"&"0"&text('Parameters-Availability'!$B$7,"mm")
&"|"&text('Parameters-Availability'!$B$7,"yyyy")
&"|"&"ST"&text('Parameters-Availability'!$B$7,"yyyymmdd")
&"|"&"Spaces"&"|"&text('Parameters-Availability'!$B$7,"ddmmyyyy")
&"|"&"THB"&"|"&Master!B4&"|1||||D|"&Master!$B$3&"|111|ZZ|ZZ|..."

Two things this settles: field 5 is "0"&text(date,"mm") — a report-month code, not a property code (August ⇒ "008", which is why the original sample's "008" didn't match any property's real ID). Field 17 is Master!$B$3 — a cell in the property's own sheet, evaluating to "SM" here. That's the actual per-property code, now editable at Admin → API Settings → Property Code. Everything else in the literal tail (1||||D| and |111|ZZ|ZZ|...) is hardcoded directly in the formula, not a reference — confirmed constant for any property.

Export logic (as implemented)

Live in sync_service.get_st_report_export — 10 fixed metric rows, values pulled from the already-imported st_files_sync row for that day, property code from property_api_settings.st_property_code.

# one entry per statistic; "key" is None for the constant-1 row
_ST_REPORT_METRICS = [
    ("90107", "Spaces",             "spaces",       "RMSST"),
    ("90100", "Occupied",           "occupied",     "PMSST"),
    ("90104", "House uses",        "house_use",    "PMSST"),
    ("90103", "Out of order",      "out_of_order", "PMSST"),
    ("90102", "Availability",      "availability", "PMSST"),
    ("90105", "Customers",         "customers",    "PMSST"),
    ("90114", "Arrivals",          "arrivals",     "PMSST"),
    ("90115", "Departures",        "departures",   "PMSST"),
    ("90101", "Complimentary Room","complimentary","PMSST"),
    ("90108", "No. of Day",        None,          "PMSST"),  # value forced to 1
]

property_code = # from property_api_settings.st_property_code - raises if unset
month_code = "0" + day.strftime("%m")   # field 5, e.g. "008" for August

for code, label, key, record_type in _ST_REPORT_METRICS:
    value = 1 if key is None else totals[key]
    row = "|".join([
        "PMSST", record_type, code, ddmmyyyy, month_code, str(year),
        f"ST{yyyymmdd}", label, ddmmyyyy, "THB", str(value), "1",
        "", "", "", "D", property_code, "111", "ZZ", "ZZ",
    ] + [""] * 21)
